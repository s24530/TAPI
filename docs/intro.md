# Space API Documentation

This API provides detailed information about [galaxies](./api-description//galaxies.md), [planets](./api-description//planets.md), and [moons](./api-description//moons.md), each accessible via their own separate routes. You can retrieve data for each entity with simple HTTP requests. The creator decided to create this API since he is a great passionate of the subjet. The data and endpoints for each object are included in their own dedicated file which you can acces via links in their names or using the menu on the left.

## Base URL

Under this URL you can find all basic routes leading to all objects that you can find in this project

```
http://localhost:4000
```
